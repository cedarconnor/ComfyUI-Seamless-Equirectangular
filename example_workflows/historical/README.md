# Historical canvas workflow

`Burgstall-T2V-two-stage-pre-20261020.json` preserves the former main T2V example before the October 20 workflow migration. It uses older model filenames, panorama LoRA, rolling, EquiRoPE and two-stage/upscale settings. Its contents are retained for comparison, not as the current default. Dependencies and output quality are not qualified on the current installation.

Use the [current workflow index](../README.md) for the spherical wrap profiles. The original graph also remains available in Git history.
